# 1. Record architecture decisions

Date: 2026-10-01 · Status: Accepted

## Context

`docs/ARCHITECTURE.md` is the approved design. Decisions made while building
— and any change to that design — need a durable, reviewable record.

## Decision

Each architectural decision gets a short numbered file in `docs/adr/`:
context, decision, consequences. An ADR that changes the approved design says
so explicitly and is agreed before the code changes. Superseded ADRs are kept
and marked, not deleted.

## Consequences

`ARCHITECTURE.md` stays the overview; ADRs carry the history and reasons.
